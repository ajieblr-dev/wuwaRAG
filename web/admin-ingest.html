Re-ingestion

Runs a long synchronous request against POST /api/v1/ingest. There is no job id to poll — the request stays open until the server responds.

Spaces are normalized to underscores. Leave blank to ingest the default set.

Re-ingestion upserts deterministic IDs, so re-running should not create duplicates. The response shape is not documented — the raw JSON is shown as-is.
