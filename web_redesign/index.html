SYSTEM ARCHITECTURE

Every stage is inspectable.

How a user question transforms into a grounded, verified answer with citations.

STAGE 01

1. Contextual Query Rewriting

Multi-turn follow-up queries like "What happened to them next?" are expanded using previous dialogue turns into standalone search queries before embedding.

STAGE 02

2. Dense & Lexical Retrieval

Runs parallel searches: 384-dimensional dense semantic vector search via Qdrant, combined with BM25 keyword scroll across title, character names, and scene dialogues.

STAGE 03

3. Reciprocal Rank Fusion (RRF)

Fuses candidate results using RRF score formula 1 / (60 + rank), giving equal weight to exact keyword hits and broad semantic matches.
